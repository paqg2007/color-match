# Color Mix Match

An original color mixing game made for class. Pick a paint, drag on the canvas
to mix it in, and match the color of the object. You need 90% accuracy to pass
each level.

Play it at https://paqg2007.github.io/color-match/

Single self-contained file (`index.html`), no build step, no external assets.
It also works offline: download the file and open it in a browser.

Inspired by color matching games in general. All code, colors and level
designs are original.
